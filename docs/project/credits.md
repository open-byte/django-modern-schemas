# Credits and Stewardship

## Open Byte

Django Modern Schemas is maintained by [Open Byte](https://github.com/open-byte).
Open Byte stewards the current implementation, documentation, releases, and
future technical direction of the project.

## Foundation

This project is a new evolution of
[Ninja Schema](https://github.com/eadwinCode/ninja-schema). It is continued with
permission from the original creator.

Special thanks and full recognition go to
[Tochukwu (@eadwinCode)](https://github.com/eadwinCode), creator of
[Ninja Schema](https://github.com/eadwinCode/ninja-schema) and
[Django Ninja Extra](https://github.com/eadwinCode/django-ninja-extra). The
original work, design, and investment are explicitly credited.

## Inspiration

Django Modern Schemas is also inspired by
[Django Ninja](https://django-ninja.dev/) and
[djantic](https://jordaneremieff.github.io/djantic/).

## Documentation Policy

The documentation renders Python examples directly from `examples/`. Those
examples are executed by the test suite, and the Material site is built with
strict link and snippet validation in continuous integration.
